# CIRA Technology - Cloned Website

A complete, high-fidelity clone of [ciratechnology.com](https://ciratechnology.com/).

## Project Features
- **Original React Architecture**: Extracted with full component hierarchy (`Navbar`, `Home`, `AboutUs`, `ContactPage`, `Founder`, `Services`, `ProductLists`, `ProductDetails`, `PdfViewerModal`, `IndustrySolutions`, `Footer`, etc.).
- **All Assets Included**: 80+ high-resolution product images, brand logos, industry photography, and PDF spec sheets stored locally under `src/components/images/` and `public/pdf/`.
- **Interactive PDF Viewer**: Embedded modal viewer with download, zoom, fullscreen, and print features.
- **Modern Tooling**: Powered by Vite + React for ultra-fast dev server and optimized production builds.

## Running the Project

### Development Server
```bash
npm run dev
# or
npm start
```
Runs at: [http://localhost:3000](http://localhost:3000)

### Production Build
```bash
npm run build
```
Creates an optimized production bundle inside `dist/`.

### Preview Production Build
```bash
npm run preview
```
Previews the built `dist/` bundle on a local server.
